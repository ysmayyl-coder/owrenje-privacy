# Öwrenje — privacy policy and support

The public pages for the **Öwrenje** language-learning app, linked from its
Google Play and App Store listings:

- privacy policy — <https://ysmayyl-coder.github.io/owrenje-privacy/>
- support — <https://ysmayyl-coder.github.io/owrenje-privacy/support.html>

Each has a Russian version, reachable from the switcher at the top of the page.

These files are generated — do not edit them here. The source is `store/` in
the app repository, and the site is rebuilt with:

    python3 store/tools/build_store_site.py --email <contact address>

A page still marked DRAFT is left out of the build, so an unreviewed
translation cannot appear on this site.

(The repository is named for the policy because that came first; it serves both
pages. Renaming it would break a URL already filed with Google.)
